Navidrome

Qobuz

Qobuz's email+password login is currently broken on their end for third-party apps (401 "Invalid credentials" even with a correct password). Use an auth token instead; switch it on below.

Getting your user ID and auth token:
  1. Log in at play.qobuz.com in your browser as usual.
  2. Open DevTools → Network tab, reload the page.
  3. Find the request to user/login and open its response.
  4. Copy user.id into "User ID" and user_auth_token into "Auth token" below.
It's a session credential, not a one-time secret. If downloads start failing later, grab a fresh one the same way.

Tidal

Conversion

Downloads location & naming

Files land at <download folder>/<subfolder>/<folder format>/<track format>. In the container, that's under wherever you mounted /music on the host (or in Navidrome's own container); on desktop, it's the folder picked above, or Music\Lucid by default. Point Navidrome's library at that same path and it will pick new albums up on its own scan schedule, or immediately after each download if Navidrome is configured above.

Custom tags

Only fields you change are applied. The file is filed under Artist / Album, and suggestions use Qobuz's own spelling, so it matches what a Qobuz download of that artist would be tagged as.
